# Explicitly Deferred or Out-of-Scope Areas

canonical_rule_id: JF_DL_DEFERRED_SCOPE_RULE
source_section_id: 10::DEFERRED_SCOPE

This candidate does not implement Repository Cache, persistent Capsule state, Feature Slice Cache, full long-term repository content cache, full JoyKeep migration, a formal installation/update system, a universal cross-Codex hard hook, user identity authentication, immutable event history, a trusted GitHub observer service, automatic approval, automatic acceptance, automatic merge or automatic promotion. These capabilities may not be inferred from interfaces in this package.

canonical_rule_id: RULE_SOURCE_REPLAY_IS_NOT_TRUSTED_OBSERVER
source_section_id: 10::SOURCE_REPLAY_IS_NOT_TRUSTED_OBSERVER

Current-source replay is a bounded invocation of the existing Validator or repository CI against materials supplied for the current task. It does not continuously watch GitHub, authenticate Brain or Codex identity, sign Evidence, maintain an immutable history, create Repository Cache or autonomously advance a stage. It only prevents Brain or Codex from obtaining material effect from deterministic facts that the current source does not reproduce.


A sparse repository-contained `LONG_TERM_STRUCTURAL_PROJECTION` is not a Repository Cache or competing truth source. It stores only reviewed derived architecture skeleton claims anchored to exact repository source bytes and is invalidated for current use by relevant source change/conflict. Current repository replay always outranks it.
