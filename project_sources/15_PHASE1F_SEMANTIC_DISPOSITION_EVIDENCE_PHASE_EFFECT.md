# Phase 1F Semantic Disposition, Evidence and Phase Effect

canonical_rule_id: RULE_LEGACY_DISPOSITION_DECISION_SEPARATION
source_section_id: 15::LEGACY_DISPOSITION_DECISION_SEPARATION

The Web Brain owns technical disposition decisions that preserve the currently confirmed product direction. User decision is required only when a disposition changes a confirmed product requirement, important tradeoff, non-goal, authority topology or key user Gate. A semantic mapping candidate cannot itself defer, retire or carry forward a historical rule, and no per-row user approval is required for Brain-owned technical closure.

canonical_rule_id: RULE_DERIVED_TARGET_BEHAVIOR_STATUS
source_section_id: 15::DERIVED_TARGET_BEHAVIOR_STATUS

Current target behavior status and verified/unverified target sets are derived only from per-target behavior-strength evidence.

canonical_rule_id: RULE_LEGACY_PHASE_EFFECT_SEPARATION
source_section_id: 15::LEGACY_PHASE_EFFECT_SEPARATION

PR1F mechanism effect is distinct from semantic evidence, disposition closure and global Phase 1 completion. An unresolved historical semantic relation may remain non-blocking for the truthful classification mechanism without becoming closed, and this artifact does not determine Phase 1 completion.

canonical_rule_id: RULE_CAPABILITY_STATUS_NAVIGATION_ONLY
source_section_id: 15::CAPABILITY_STATUS_NAVIGATION_ONLY

CAPABILITY_STATUS is a generated non-authoritative navigation view and cannot satisfy a Stage or Phase Gate.

canonical_rule_id: RULE_CAPABILITY_EVIDENCE_CONTRACT_BINDING
source_section_id: 15::CAPABILITY_EVIDENCE_CONTRACT_BINDING

Each capability evidence reference binds an exact verification contract digest and an allowed capability subject.
