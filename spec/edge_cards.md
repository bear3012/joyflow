# Edge Cards

## E0: H0_RAW_HUMAN_INTENT → H1_ASSOCIATIVE_DISCUSSION

Raw intent must be explored before it is frozen.

## E1: H1_ASSOCIATIVE_DISCUSSION → H2_INTENT_CALIBRATION

Brain presents interpretations, concrete consequences, risks, and tradeoffs; the human calibrates product meaning.

## E2: H2_INTENT_CALIBRATION → H3_PRODUCT_WALKTHROUGH

Only calibrated intent may become a concrete use walkthrough.

## E3: H3_PRODUCT_WALKTHROUGH → H4_PRODUCT_MEANING_CLOSURE

The human confirms actual behavior. Brain records the closure and distinguishes material ambiguity from harmless wording variation.

## E4: H4_PRODUCT_MEANING_CLOSURE → H5_DUAL_LAYER_TRANSLATION_CONTRACT

Only confirmed, no-material-ambiguity meaning may be compiled into an execution contract.

## E5: H5_DUAL_LAYER_TRANSLATION_CONTRACT → H6_GOLDEN_CASE_AND_USER_ACCEPTANCE_PLAN

The contract must be grounded in stable positive/negative behavior examples and predefined human acceptance.

## E6: H6_GOLDEN_CASE_AND_USER_ACCEPTANCE_PLAN → R0_CONTRACT_RED_TEAM_REVIEW

Review attacks ambiguity, false-pass risk, overdesign, acceptance weakness, and mechanical boundary gaps.

## E7: R0_CONTRACT_RED_TEAM_REVIEW → N1_ROUTE_TASK

Routing respects the receipt. `BLOCK` forces HARD_STOP_LANE.

## E8: N1_ROUTE_TASK → N3_BUILD_BRIDGE

Routing, confirmed meaning, contract, and interpretation gates become bridge inputs.

## E9: N3_BUILD_BRIDGE → N4_BUILD_CONTEXT_PALACE

Context palace is derived from bridge only and cannot create new authority.

## E10: N4_BUILD_CONTEXT_PALACE → N5A_BUILD_CODEX_INTERPRETATION_REQUEST

Non-LEAN tasks receive a short read-only interpretation request before executable release.

## E11: N5A_BUILD_CODEX_INTERPRETATION_REQUEST → N5B_CODEX_EXECUTION_INTERPRETATION

Codex returns understanding, exclusions, solution surface, Golden Case IDs, unresolved items, and status without modifying files.

## E12: N5B_CODEX_EXECUTION_INTERPRETATION → N5C_BRAIN_INTERPRETATION_REVIEW

Brain compares Codex interpretation to confirmed product meaning and contract. Only aligned understanding may proceed.

## E13: N5C_BRAIN_INTERPRETATION_REVIEW → N5_BUILD_CODEX_PACKET

Brain releases one complete execution Prompt after alignment. A valid LEAN task may embed the same interpretation fields and skip the separate transfer.

## E14: N5_BUILD_CODEX_PACKET → N6_HUMAN_HANDOVER_TO_CODEX_APP

Human handoff is mandatory. The user does not assemble instruction fragments.

## E15: N6_HUMAN_HANDOVER_TO_CODEX_APP → N7_CODEX_APP_EXECUTION

Codex executes only if packet, bridge, product closure, and interpretation all allow execution.

## E16: N7_CODEX_APP_EXECUTION → N8_RUN_CHECKS

Checks and Golden Case evidence run before evidence return. Deviations use the three-level routing rule.

## E17: N8_RUN_CHECKS → N9_RETURN_EVIDENCE_TO_BRAIN

Raw machine evidence, actual diff, Golden Case results, and deviation record return to Brain.

## E18: N9_RETURN_EVIDENCE_TO_BRAIN → N9A_BRAIN_SEMANTIC_REVIEW

Brain re-checks the original problem, semantic/scope drift, overdesign, and practically-wrong risk.

## E19: N9A_BRAIN_SEMANTIC_REVIEW → N10_USER_ACCEPTANCE

Only a Brain-reviewed result proceeds to the predefined human product test. Brain review does not replace the user's lived-experience judgment.

## E20: N10_USER_ACCEPTANCE → N11_RECONCILE

Reconcile requires exact coverage of the contract-time acceptance plan and a declared result.

## E21: N11_RECONCILE → N12_HUMAN_CLOSE_OR_REJECT

Human remains the final closer even when all machine and Brain gates pass.
