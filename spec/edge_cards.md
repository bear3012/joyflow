# Edge Cards

## Meaning to contract

Only user-confirmed meaning with no material ambiguity may become an ACTIVE_TASK contract.

## Contract to routing

Routing uses intended change surfaces, not negative statements. Reference candidates are non-executable.

## Interpretation to execution

A non-LEAN ACTIVE_TASK requires authentic Codex return plus Brain alignment. A fixture cannot cross this edge.

## Bridge to handoff

The one complete packet must be fresh and must bind all semantic inputs. CI rejects any deterministic generated-file diff after refresh.

## Execution to evidence

Codex may write only allowed source paths and executor outputs. Brain and human approval artifacts are excluded.

## Evidence to closure

All evidence must bind current HEAD, Bridge, input bundle, source bundle, task ID, and acceptance plan. HARD_STOP or HALT cannot close even if a receipt says PASS.
